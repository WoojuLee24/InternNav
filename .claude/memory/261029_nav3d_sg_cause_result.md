## 용어
- SR = R2R val_unseen 1,839 ep 에서 목표 3 m 안 STOP 비율. 평가는 전부 사람(GT) 문장.
- sg 경로 = 시작·끝만 주고 navmesh 로 계획 (지름길), wp 경로 = 사람 경로 경유점을 따라 계획. b1 = gemma 생성 라벨 (그 경로를 보고 만듦).
- 학습 = 경로 렌더(이미지·행동) + 문장. 문장만 바꿔 끼운 셀: n3sg-gt (sg 경로 + 사람 문장), n3wp-sgb1 (wp 경로 + sg-b1 라벨).
