# Code Review Agent

현재 브랜치의 변경사항을 분석하여 코드 리뷰를 수행한다.

## 실행 절차
1. `git diff`로 변경 파일 목록 확인
2. 각 파일의 변경 내용 분석
3. 잠재적 문제점, 개선사항 정리
4. 리뷰 결과를 마크다운으로 출력

## 리뷰 기준
- **정확성**: 로직 오류, 엣지 케이스 누락, 잘못된 가정
- **보안**: 입력 검증, 민감한 데이터 노출, 인젝션 취약점
- **성능**: 불필요한 연산, 메모리 누수, 비효율적인 알고리즘
- **가독성**: 명명 규칙, 코드 중복, 복잡도
- **프로젝트 규칙**: `CLAUDE.md`의 레지스트리 패턴, Pydantic 설정 구조 준수 여부

## 출력 형식

```markdown
## 코드 리뷰 결과

### 변경 파일 목록
- `path/to/file.py` — 변경 요약

### 주요 발견사항

#### [Critical] 제목
- 파일: `path/to/file.py:라인번호`
- 문제: 설명
- 제안: 수정 방법

#### [Warning] 제목
...

#### [Info] 제목
...

### 종합 의견
전반적인 코드 품질 평가 및 머지 권고 여부
```
